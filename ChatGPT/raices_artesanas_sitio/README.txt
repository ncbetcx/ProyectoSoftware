# Raíces Artesanas — sitio estático

## Estructura
- `index.html` — página principal
- `articulos.html` — catálogo completo
- `tejidos.html` — categoría tejidos
- `ceramicas.html` — categoría cerámicas
- `pinturas.html` — categoría pinturas
- `contacto.html` — formulario de contacto
- `nosotros.html` — información sobre quién mantiene el sitio
- `estilosIA.css` — hoja de estilos externa
- `articulos/` — imágenes PNG y fichas PDF de cada producto

## Tecnologías
Sólo HTML y CSS para la interfaz. No se utiliza JavaScript.

## Nota sobre el formulario
El formulario usa `mailto:artesanias@example.com` como ejemplo. Reemplazá esa dirección por el correo real del emprendimiento. Al ser un sitio estático, no hay servidor que procese ni almacene los formularios.

## Accesibilidad
Se incorporaron:
- HTML semántico.
- Etiquetas asociadas a todos los campos del formulario.
- Texto alternativo en imágenes.
- Enlace para saltar al contenido.
- Estados de foco visibles.
- Contraste reforzado.
- Navegación que no depende exclusivamente del color.
- Diseño responsive para pantallas pequeñas.
- Respeto por `prefers-reduced-motion`.
